# Mico

Mico is a macOS utility that turns the space around a MacBook into a programmable interaction surface.

## Product direction

Define virtual zones around the MacBook and assign local actions to them. Zones can be used for app launching, websites, shortcuts, files, shell commands, media controls, screenshots, and custom actions.

## Development principles

- macOS-first and local-first
- Swift + SwiftUI for the native application
- No cloud dependency for core interactions
- Explicit permissions and transparent automation
- Profiles for different workflows
- Modular action system so new actions can be added without redesigning the UI
